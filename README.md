### Cloud Computing course project

Java-based backend that exposes a REST API for managing houses, rentals, media, periods, questions and users. It uses Jakarta / Resteasy for JAX-RS endpoints, Azure Cosmos DB for persistence, Redis for session/cache storage and Azure Blob Storage for media; it is intended to be deployed to a servlet container (Tomcat) or directly to Azure Web Apps.
